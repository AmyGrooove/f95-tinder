# Кодик — интересующие данные о фильмах

Поля и примеры приведены по результатам изучения API пользователем, без независимой проверки ответа API. Документ описывает данные для будущего сборщика, а не реализованный парсер. Дополнительные найденные поля не считаются автоматически выбранными для каталога.

## Ранее выбранные данные о фильмах

Уточнённые пути первоначального списка. Поля верхнего уровня и поля внутри `material_data` перечислены отдельно, даже если они описывают похожие сведения.

## Дополнительные сведения об аниме и дорамах

Наличие этих полей не расширяет текущий этап до поддержки сериалов, мультфильмов или аниме. Тип movie включает только фильмы, в том числе документальные. Сериалы, мини-сериалы и другие многосерийные произведения, включая документальные сериалы, а также анимационные произведения исключены. Поля аниме сохраняются здесь как описание найденных данных источника, а не как состав карточки movie. Примеры относятся к разным материалам и не образуют одну карточку фильма.

## Уточнения перед реализацией

- `other_title` на верхнем уровне и `material_data.other_titles` — разные поля: одно название и список названий соответственно.
- Приоритет между одноимёнными полями верхнего уровня и `material_data`, а также объединение кадров определяются при нормализации.
- `created_at` и `updated_at` не являются датами выпуска произведения. Пригодность `updated_at` для инкрементального сбора требует проверки API.
- Язык текста, включая `material_data.title_en`, необходимо проверить перед записью в соответствующую локализацию каталога.
- Наличие внешних идентификаторов помогает сопоставлению записей; данные о качестве, переводах и блокировках не становятся характеристиками произведения автоматически.

Объект источника для начального наполнения БД находится в [import/sources/kodik.json](../../../../../import/sources/kodik.json).

Обязательность полей, пустые значения, полнота сведений и правила преобразования в данные каталога уточняются при реализации сборщика и импорта.
