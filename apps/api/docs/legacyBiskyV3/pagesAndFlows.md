Названия путей фронтенда в макетах не заданы. Отдельная [сверка с кодом](implementation.md) фиксирует подтверждённые точки входа и отличия реализации от макетов; это не запись прохождения переходов.

## Общие элементы интерфейса

Desktop-шапка содержит логотип, коллекции, инструменты, AnimePass, поиск с подсказкой `Ctrl + K`, уведомления и аватар. Подвал содержит ссылки «О сайте», «Поддержка», «API», документы, соцсети и копирайт.

На mobile есть компактная шапка и нижняя панель навигации. Содержимое некоторых крупных блоков вынесено в вкладки или дополнительные окна. В частности, для клубов и персон явно есть мобильные вкладки «Инфо», а компактный АниПик не выводит рядом весь текст desktop-карточки.

На PNG меню аккаунта `4181:35046` видны имя с иконкой копирования, профиль, настройки и поддержка; меню `4181:35039` содержит главную и коллекции. Мобильный «Быстрый доступ» `4201:16912` объединяет AnimePass, настройки, поддержку, три инструмента и факт с источником/автором. В нижней панели — четыре иконки: дом, поиск, пользователь и быстрый доступ; активный раздел выделен цветом. Это отдельная мобильная композиция, а не уменьшенная desktop-шапка.

## Как читать реестры

В [desktop](screensDesktop.md), [mobile](screensMobile.md), [модальных окнах](screensModals.md) и [меню](screensMenus.md) есть запись на каждый фрейм. ID определяет конкретный вариант даже при совпадении названия. Каждой из 187 записей соответствует существующий локальный PNG. Архивный размер фрейма и размер экспорта указаны отдельно; имена пользователя сохранены. Например, `Авторизация` обозначает несколько разных шагов, а один мобильный фрейм `Список аниме` фактически содержит комментарии.

Связи между страницами в тематических описаниях восстановлены по кнопкам и текстам; кликабельный прототип не проходился. Поведение иконки без явной подписи не считается установленным только по её внешнему виду.

## Связи страниц с локальными окнами и меню

| Контекст | Подтверждённое содержимое отдельного экспорта | Граница наблюдения |
| --- | --- | --- |
| Вход и настройки | Выбор способа входа, пароль/OAuth, почта → шесть ячеек кода → новый пароль; менеджер сессий | Шаги формы видны отдельно, переходы и запросы не выполнялись |
| Карточка / личный список | Два варианта быстрого статуса, постановка/изменение оценки, полная правка личной записи и вкладка серий | «Удалить» и «Пересмотреть» — действия; их нельзя превращать в дополнительные enum по изображению |
| Коллекция | Создание и прямое редактирование с «Создать»/«Сохранить»; предложение правки с причиной и «Отправить» | Различие форм видно; права владельца и модерации требуют реализации |
| Аниме, клуб, персона | Информация и редактирование связанных списков; у аниме отдельно плеер и серии | Повторённые карточки — заполнители; порядок и допустимые связи не выводятся из них |
| Плеер | Выбор серии, скорость, качество, три переключателя | Возможности конкретного источника видео и сохранение настроек неизвестны |
| Комментарии / уведомления | Жалоба либо редактирование/удаление; «Удалить все» уведомления | Отдельные варианты не устанавливают матрицу прав и область массового удаления |
| Выдача | Шесть наборов SortMenu и общий аниме-фильтр | Привязка каждого SortMenu к странице и query не установлены |

Подробные ссылки на конкретные варианты — в [окнах](screensModals.md) и [меню](screensMenus.md). Эти связи помогают читать архив; наличие соответствующего окна не означает, что каждый похожий значок обязательно открывает его.
