# Архив предыдущего Bisky: Swagger и Bisky_v3

Старые макеты и Swagger — **референсы для исследования возможных страниц, данных и сценариев нового приложения**. Они не являются обязательным дизайном, архитектурой, контрактом API или согласованным объёмом нового Bisky. Приоритет имеют [основы](../product/foundations.md), [MVP](../product/mvpScope.md) и [контракт аккаунта](../api/accountAndAuthSpec.md); архив их не изменяет.

Обновлено 24 октября 2026 года по всем **187 локальным PNG** пользователя: 58 Desktop, 60 Mobile, 55 Modals и 14 MiniMenu. Изображения изучены как визуальная основа для последующей адаптации проекта. Основные документы проекта в этом обновлении не меняются. Прежние сведения о странице Pages файла Bisky_v3 сохранены; повторного обращения к Figma не было.

## Источники и реестры

- [swaggerOriginal.txt](swaggerOriginal.txt) — дословный прежний текстовый список. OpenAPI и изображений Swagger нет.
- [swaggerEndpoints.json](swaggerEndpoints.json) — все 100 исходных записей без изменения методов, путей, описаний и порядка.
- [screenApiMap.json](screenApiMap.json) — те же 100 записей со связями и оговорками; `screenshots` содержит PNG всех сопоставленных групп, `desktopScreenshots` сохраняет desktop-подмножество. Это не новый API и не доказательство фактических вызовов.
- [screensManifest.json](screensManifest.json) — 187 фреймов с существующим `screenshot`, размером PNG, SHA-256, датой просмотра и наблюдением. `width`/`height` сохраняют архивный размер фрейма, `renderWidth`/`renderHeight` — размер PNG. `previousFile` сохраняет прежний путь; `file` указывает текущий файл относительно папки screenshots. Исторический `desktopRefresh` сохранён; текущее покрытие описывает `localExportRefresh`.
- [figmaTexts.json](figmaTexts.json) — прежнее извлечение текстов 187 фреймов, без нового OCR или чтения Figma. При расхождении описание текущего изображения имеет приоритет; старый текст остаётся источником сравнения, а не точной копией PNG.
- В `screenshots/desktop`, `mobile`, `modals`, `miniMenu` сохранены имена и байты пользовательских файлов. Кириллица, пробелы, опечатки и суффиксы вариантов не исправлялись; Markdown-ссылки кодируют специальные символы.

## Полнота и границы проверки

1. Изучены текущие изображения, поэкранные реестры и тематические описания архива. Прежняя сверка с требованиями и исходниками сохранена отдельно; это обновление не является новым аудитом реализации.
2. Просмотрены все 187 PNG, в том числе полная экспортированная область длинных страниц. Конец изображения не доказывает конец страницы: часть мобильных списков обрезана границей макета, а нижняя навигация перекрывает содержимое.
3. Каждое изображение сопоставлено с одним прежним фреймом по имени, варианту и содержимому; размеры дополнительно проверены. Figma ID взяты из старого реестра, не извлечены из PNG. У большинства окон и меню экспорт на 8 px шире и выше фрейма; оба размера сохранены без предположения о причине.
4. Для 129 mobile/модальных/меню PNG добавлены отдельные визуальные наблюдения. Desktop-описания сохранены и связаны с текущими именами. Открытые меню теперь доступны отдельно, но их наличие не доказывает конкретный переход из закрытого меню на странице.
5. Старые приложение и сервер не запускались; переходы, HTTP-запросы, доступность кнопок и серверные правила не проверялись. Сетевая доступность Figma и старых внешних ссылок не проверялась.

**Наблюдение** — видимый блок, подпись или состояние. **Сопоставление** — кандидат связи со старым маршрутом. **Предложение** — вариант для нового продукта, требующий отдельного решения. Неподписанные иконки, числа и даты не получают выдуманного значения; повторённые карточки не задают лимиты и формулы.

24 октября 2026 года добавлена [статическая сверка с исходниками](implementation.md). Она уточняет часть API и серверных правил, но не является сетевой трассировкой или новым просмотром Figma. Для кода фиксируются коммиты: локальный `main`, `origin/main` и `dev` могут содержать разные реализации. Архивные 100 записей Swagger и реестры изображений сохранены как исходные свидетельства, включая расхождения с кодом.
