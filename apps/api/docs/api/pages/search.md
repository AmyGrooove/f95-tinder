## Текущее покрытие

| Сценарий                                       | Состояние          | Основание                                                                                                                             |
| ---------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Каталог произведений, поиск и фильтры          | Нет                | Нет самостоятельных публичных маршрутов Item и глобальных справочников фильтров                                                       |
| Каталог и поиск коллекций                      | Частично           | QUERY /collections выдаёт краткие карточки с фильтрами itemIds/type и пагинацией; текстового поиска и остальных фильтров каталога нет |
| Карточки с общими оценками и личным состоянием | Частично           | В составе коллекции возвращаются Item id/type/title/media и часть UserItem, но это не глобальная выдача и в ней нет общей оценки      |
| Личные действия                                | Реализована запись | Переиспользовать [общие операции](shared.md), не создавать их повторно для каталога                                                   |

## Осталось

- [ ] `SEARCH-01`: определить и реализовать каталог movie без обязательного запроса, поиск по основным и альтернативным названиям, пагинацию по страницам. Фильтры: тип, жанры/теги, год, длительность, страна, статус выпуска и общая оценка. Сортировки: соответствие, популярность, общая оценка, выход и название.
- [ ] `SEARCH-02`: определить и реализовать получение доступных справочников/значений фильтров произведений. Коллекционные фасеты ограничены составом конкретной коллекции и не заменяют глобальные данные.
- [ ] `SEARCH-03`: базовая выдача с itemIds/type и сортировкой по новизне есть в QUERY /collections. Общесайтовый поиск согласуется отдельно, без текстового поиска в этом маршруте. Остаются поиск по названию, фильтры от сайта/пользовательские, мои, избранные и исключение скрытых; сортировки по соответствию, общей оценке и названию. Карточке нужны обложка, автор, размер и общая оценка; текущая краткая выдача не содержит размера и оценки.
- [ ] `SEARCH-04`: подключить личное состояние и условия произведений: статусы, избранное, личная оценка, наличие/отсутствие в библиотеке, скрытие completed/dropped и «Не рекомендовать». Использовать `LIB-02` и `REC-02` без раскрытия приватных данных.
- [ ] `SEARCH-05`: определить и реализовать режим рекомендаций и переходы с главной с сохранением условий блока. Переиспользовать `REC-01`, не подменять обычный поиск рекомендательной выдачей.

## Уточнить

Диапазоны и сочетания фильтров, иерархию тегов, сортировку без запроса и направления, размер страницы, формулу популярности, контракт рекомендательного режима и точный состав кратких карточек. Новые URL и DTO здесь не назначаются.

Анонсы по умолчанию участвуют в обычном каталоге. Личные статусы и «Не рекомендовать» не исключают произведения без явно выбранного условия. Скрытые коллекции также доступны по умолчанию, пользовательские коллекции участвуют в прямом поиске без условия допуска на главную. В рекомендательном режиме исключение «Не рекомендовать» обязательно.

## Проверка результата

Проверять поиск по альтернативным названиям, совместное применение условий и пагинации, различия обычного и рекомендательного режимов, гостевые/личные поля, отсутствие нуля вместо неизвестной оценки. Сохранение query в URL страницы — задача клиента. Runtime-проверки не выполнялись.
