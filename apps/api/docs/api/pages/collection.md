# Просмотр коллекции: покрытие API

[Индекс покрытия](readme.md) · [Требования страницы](../../product/pages/collection.md) · [Контракт коллекций](../collectionsSpec.md)

## Реализовано

| Маршрут | Покрытие |
| --- | --- |
| `GET /collections/:id` | Метаданные, authorId, version, медиа, полная структура group/text без списков Item, даты |
| `QUERY /collections/:id/items` | Единая пагинация Item, grouped/flat, авторский порядок или название, поиск, теги/характеристики и диапазон общей оценки; заметки включений |
| `GET /collections/:id/filters` | Доступные теги, числовые/датовые/булевы характеристики и режимы всей подборки; без query |
| `GET /collections/:id/user` | Собственная оценка коллекции, избранное и скрытие |
| `PATCH /collections/:id/rating` | Целая оценка 1–10 или null; автору нельзя поставить оценку своей коллекции |
| `PATCH /collections/:id/favorite` | Избранное коллекции |
| `PATCH /collections/:id/hidden` | Личное скрытие, без запрета прямого чтения |
| `DELETE /collections/:id` | Мягкое удаление автором; операция редактора также доступна отсюда |

Код: [CollectionReadController](../../../src/endpoints/collection/controllers/collectionRead.controller.ts), [CollectionContentService](../../../src/endpoints/collection/services/collectionContent.service.ts), [CollectionService](../../../src/endpoints/collection/services/collection.service.ts), [CollectionUserService](../../../src/endpoints/collection/services/collectionUser.service.ts).

Чтение состава публичное: возвращает только Item и данные включения в подборку, без userItem. Cookie авторизации не проверяется. Краткий QUERY /userItems читает состояние по известным ID UserItem; для карточек состава, где доступны только ID Item, поиск личной записи по Item ещё нужен (LIB-01).

Фильтры по статусу, наличию в библиотеке и избранному, а также «Скрыть завершённое» исключены из объёма страницы. ratingMin/ratingMax фильтруют по сохранённой общей оценке ItemMetric.ratingAverage до пагинации и доступны гостям. Расчёт/обновление метрики пока не реализованы (ITEM-02); неизвестная оценка исключается при активном диапазоне.

## Чего не хватает

| ID | Состояние | Пробел |
| --- | --- | --- |
| COLLECTION-01 | Частично | Шапка содержит authorId, но не публичное представление автора; нет общей оценки/числа оценок и избранного. total состава — число совпадений с фильтрами, а не гарантированное число всей коллекции |
| COLLECTION-02 | Нет | Нет «Завершено X из Y» по всей коллекции независимо от фильтров и страницы |
| Карточки произведений | Частично | Личное состояние требует отдельного чтения LIB-01; ответ `/items` не содержит общей оценки Item; расширение согласовать с `ITEM-03` |
| Запуск Баттла | Частично | Источник состава есть; подготовка набора и остальная ответственность описаны в `BATTLE-01/02` |

- [ ] `COLLECTION-01`: определить расчёт/обновление и чтение общей статистики, полного числа доступных произведений и публичных данных автора/отметки сайта. Использовать `PROFILE-01` или согласованное краткое представление автора; не раскрывать защищённый `/account`.
- [ ] `COLLECTION-02`: определить и реализовать полный личный прогресс X/Y, учитывая удалённые произведения. Не рассчитывать его по одной странице или выдаче с активными фильтрами.

## Уточнить

Формулы статистики, правила X/Y при удалённых Item, пустые состояния и переход в настройку Баттла. Официальность определяется `authorId=null`; обычные пользовательские маршруты не управляют коллекциями сайта. Административные операции не входят в задачу страницы.

## Проверка результата

Проверять неизменность X/Y и общей статистики при смене страницы/фильтров, гостевое чтение, независимость реакций от библиотеки и отсутствие запрета прямого чтения после скрытия. 25 октября 2026 года локально прошли 38 unit- и 126 HTTP-интеграционных тестов подборок на одноразовых MongoDB 8.0.17 и Redis 8.2.3. Для чтения состава проверены публичный ответ без UserItem, игнорирование cookie, отказ от удалённых личных фильтров, диапазон сохранённой общей оценки и пагинация после фильтрации. Это не проверка рабочего API или БД; расчёт метрик и полный личный прогресс остаются нереализованными.
