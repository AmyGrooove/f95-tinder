# ITEM-01 — публичная карточка произведения

- [x] Реализовать `GET /items/:id` для публичного чтения карточки Item

[Схема запроса и примеры](../../api/requestFlows/catalog.md#item)

Гость может получить карточку без аутентификации. Единственный входной параметр — MongoDB ObjectId в пути (24 шестнадцатеричных символа). Тело и query-параметры отсутствуют.

Успешный ответ `200` содержит объект без обёртки.

| Поле                   | Формат                                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------------------------- |
| `id`, `type`           | Строковый ID и тип Item                                                                                  |
| `title`, `description` | `{ru, en}`, каждый перевод — строка или `null`                                                           |
| `aliases`              | Массив строк                                                                                             |
| `media`                | Массив `{src, type, language}`                                                                           |
| `tags`                 | Массив `{id, key, group, name}`                                                                          |
| `relations`            | Массив `{item: {id, type, title, media}, role: {id, key, name}}`                                         |
| `stats`                | `{ratingAverage, ratingsCount, favoritesCount, statusCounts}`                                            |
| `releaseDate`          | Дата первого выпуска или `null`                                                                          |
| `ageRestriction`       | Строка `"0"`, `"6"`, `"12"`, `"16"`, `"18"` или `"18++"` для игр, либо `null`                            |
| `movie`                | `{duration}` или `null`                                                                                  |
| `series`               | `{episodeCount, releasedEpisodeCount, episodeDuration, lastReleasedEpisodeAt, nextEpisodeAt}` или `null` |
| `game`                 | `{mainStoryDuration, fullCompletionDuration}` или `null`                                                 |

Даты передаются в ISO 8601. `lastReleasedEpisodeAt` — дата последней вышедшей серии. Внутри блоков неизвестные характеристики возвращаются как `null`. Длительности указаны в минутах. Пустые массивы возвращаются как `[]`. Названия тегов и ролей локализованы через `{ru, en}`. Поля `media.language` и `tags.group` допускают `null`.

Ответ включает прямые теги и прямые связи в обоих направлениях. Теги упорядочены по убыванию `relevanceScore`, при равенстве по ID тега. Связи упорядочены по ID связи. Роль берётся со стороны связанного произведения, её имя переопределяется отдельно для каждого заданного перевода. Строка из словаря используется для перевода без переопределения. Отсутствующие и удалённые связанные произведения и связи с отсутствующей ролью пропускаются. Связи возвращаются без рекурсии и пагинации.

`stats` читается из `ItemStats`. `ratingAverage` — средняя оценка от 1 до 10 или `null` при отсутствии оценок. `ratingsCount` и `favoritesCount` — целые неотрицательные счётчики. `statusCounts` содержит `planned`, `inProgress`, `onHold`, `completed`, `dropped`. При отсутствии `ItemStats` среднее равно `null`, все счётчики равны 0.

Личная запись доступна через [GET /items/:id/user](../../api/requestFlows/catalog.md#item-user), коллекции — через [QUERY /search](../../api/requestFlows/catalog.md#search).

| Код   | Условие                                |
| ----- | -------------------------------------- |
| `400` | Некорректный ObjectId                  |
| `404` | Item отсутствует или помечен удалённым |
| `429` | Превышен лимит запросов                |
| `500` | Необработанный сбой                    |
