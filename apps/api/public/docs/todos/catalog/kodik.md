# Вопросы сопоставления Kodik

Предложения к [сопоставлению полей](../../sources/kodik/mapping.md) сохраняют контекст обсуждения и требуют отдельного решения.

## Предложения по новым полям и группам

| Предложение                         | Сравнение с текущим вариантом                                                                                                                                               | Рекомендация                                                                                                                           |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| `Item.originalTitle: string / null` | aliases уже сохраняет текст, но теряет признак оригинального названия. Поле позволяет показывать его отдельно и использовать при сопоставлении; язык из текста не выводится | Добавлять при необходимости отдельного отображения или сопоставления именно по оригинальному названию; до решения использовать aliases |
| `Item.tagline: LanguageText`        | Сейчас слоган остаётся в исходных данных. Строковая feature теряет локализацию, смешивание с description теряет назначение                                                  | Добавлять для самостоятельного отображения слогана; до решения сохранять в исходной выгрузке, отсутствующие переводы не выдумывать     |
| Объединение групп genre и subgenre  | Отношение узкого и широкого жанров уже выражается через Tag.parents                                                                                                         | Рекомендовано как целевое упрощение; изменение enum и существующих записей выполняется отдельно после проверки потребителей и данных   |
| Feature `releaseDateWorld`          | Явно отличает мировую премьеру от российской и других дат                                                                                                                   | Использовать как целевой ключ; равнозначную releaseDate параллельно не хранить                                                         |

## Проверки перед реализацией сборщика

- Приоритет между одноимёнными полями верхнего уровня и `material_data`, а также объединение кадров определяются при нормализации.

- Пригодность `updated_at` для инкрементального сбора требует проверки API.

- Язык текста, включая `material_data.title_en`, необходимо проверить перед записью в соответствующую локализацию каталога.

Обязательность полей, пустые значения, полнота сведений и правила преобразования в данные каталога уточняются при реализации сборщика и импорта.
