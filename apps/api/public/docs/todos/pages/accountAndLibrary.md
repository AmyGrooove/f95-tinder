## Настройки

- [x] `SETTINGS-01`: [загрузка, замена и удаление собственного аватара](../../api/contracts/accountAndAuthSpec.md#аватар) через `PUT` и `DELETE /account/avatar`.

### Вопросы API

Представление ожидания подтверждений и ошибок, сессии без userAgent. Сохранение отображаемого имени и логина выполняется отдельными маршрутами. При детализации общей кнопки формы определить обработку частичного успеха. Повтор пароля, предпросмотр и предупреждение о несохранённом относятся к клиенту.

OAuth, удаление аккаунта и настройки уведомлений не являются недостающими операциями описанной страницы.

### Проверка результата

Для новых операций проверять владение, загрузку/замену/удаление и чтение итогового avatarUrl.

### Вопросы интерфейса

При подготовке интерфейса уточняются состояния подтверждений и ошибок, поведение несохранённых изменений и представление сессий без user agent.

## Профиль и библиотека

- [ ] `PROFILE-01`: [GET /users/:id](../../api/requestFlows/userItems.md#user-profile) выдаёт публичные поля профиля. Уточнить источник фона.
- [x] `PROFILE-02`: [GET /users/:id](../../api/requestFlows/userItems.md#user-profile) выдаёт дату регистрации, распределение по пяти статусам, число оценённых и избранных.
- [ ] `PROFILE-03`: [QUERY /account/library/history](../../api/requestFlows/account.md#library-history) выдаёт владельцу последние действия и историю новых событий. Определить срок хранения и поведение истории при удалении UserItem.

Вкладки используют `LIB-02`, редактор владельца использует `LIB-01`. Фильтры `SEARCH-03` по автору и пользователю, добавившему в избранное, работают для публичных коллекций в своём и чужом профиле.

### Вопросы API

Фильтры, сортировки и пагинацию библиотеки, формулы сводки, фон, публичный прогресс и сроки/правила хранения истории. Чужая библиотека, оценки и избранное публичны; заметки, подробные попытки и вся история приватны. Возможные настройки приватности ещё не определены и не добавляются предположением.

Отдельные именованные списки для пяти статусов не нужны. Управление аватаром отслеживается в [настройках](../../api/pages/settings.md), произвольные приватные списки — вне текущей карты реализации.

### Проверка результата

Проверять свой/чужой профиль и гостя, отсутствие личных заметок и попыток в публичных ответах, совпадение сводки с данными библиотеки и приватность истории после удаления записи.

### Вопросы интерфейса

При подготовке спецификации уточняются фильтры, сортировки, пагинация, расчёт сводки, оформление фона, объём публичного прогресса и правила хранения истории, включая удаление записи библиотеки. Необходимость настройки приватности отдельных публичных разделов пока не определена. Числа сводки рассчитываются по данным пользователя; формулы определяются отдельно.
