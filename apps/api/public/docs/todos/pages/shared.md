## Общие операции

| ID     | Состояние   | Результат и потребители                                                                                                                                                                             |
| ------ | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| LIB-01 | Реализовано | [GET /items/:id/user](../../api/requestFlows/catalog.md#item-user) возвращает свою актуальную запись по ID Item, включая заметку и попытки                                                          |
| LIB-02 | Реализовано | [Список библиотеки](../../api/contracts/librarySpec.md#публичный-список-библиотеки) с поиском, фильтрами, сортировкой и пагинацией. Краткий прогресс и ID записи доступны владельцу                 |
| REC-01 | Частично    | [Внутренняя выдача](../../api/readme.md#recommendations) собирает подборку авторизованному пользователю. Для главной, рекомендательного каталога и Пика ещё нужны HTTP-контракт и гостевой сценарий |
| REC-02 | Частично    | UserItem поддерживает skipped/blocked, состояния доступны через LIB-01. Внутренняя выдача исключает blocked и действующие skipped                                                                   |

- [x] `LIB-01`: реализовать чтение по Item для загрузки полного редактора.
- [x] `LIB-02`: реализовать HTTP-чтение библиотеки с собственным и публичным представлениями.
- [ ] `REC-01`: согласовать HTTP-контракт и гостевой сценарий, подключить существующую выдачу для авторизованного пользователя.
- [ ] `REC-02`: согласовать передачу [фильтров рекомендаций](../recommendations/feedFilters.md) через HTTP.

### Вопросы API

- Общие параметры чтения библиотеки, граница публичного прогресса; заметка и подробные попытки остаются приватными.
- Контракт рекомендаций и реакций, поведение повторов и обновления выдачи. Соблюдать [ограничения рекомендаций](../../research/recommendations/tagBasedV1.md), не переносить обязательные исключения в обычный поиск без явного фильтра.
- Для гостя личные действия требуют входа. Операция не выполняется автоматически после входа; отображение ошибок и обновление состояния карточки относятся также к клиенту.

### Вопросы интерфейса

Точные URL и параметры переходов, поведение системной кнопки «Назад» для окон, возврат фокуса, удержание позиции страницы и условия показа панелей определяются при детализации интерфейса. Доступность инструментов гостю и восстановление их состояния описываются отдельно для каждого инструмента.
