## Редактор коллекции

- [x] `EDITOR-01`: загрузка обложки автором через [`PUT /collections/:id/poster`](../../api/requestFlows/collections.md#poster).
- [ ] `EDITOR-02`: согласовать сценарий загрузки/редактирования постраничного состава и обработки 409. Публичный `/items` возвращает стабильные ID групп. В карточках по-прежнему нет отдельных `groupId` и `position`, а у текстовых блоков в составе нет ID. Определить минимальное чтение для редактора, сохранив единый PATCH.

Поиск добавляемых произведений — зависимость `SEARCH-01/02`, а не новый поиск внутри редактора. Для превью выбранного произведения нужны публичные данные `ITEM-01`.

### Вопросы API

Выбор типа коллекции, работа с RU/EN, требования к обложке, сохранение формы при конфликте версии и при частично загруженном составе. Очерёдность локальных действий, кнопка сохранения и предупреждение об уходе относятся к клиенту; сервер уже выполняет единый PATCH атомарно. Управление официальными коллекциями обычному автору не предоставляется.

### Проверка результата

Проверять сохранение перестановок и переносов без потери незагруженных включений, конфликты version, уникальность Item, удаление группы и отсутствие изменений библиотеки.

### Вопросы API

В модели официальность определяется `author=null`. Публичный DTO также возвращает null при отсутствующем User, поэтому явный признак официальности требует уточнения контракта. Обычные пользовательские маршруты не управляют коллекциями сайта. Переход в настройку Баттла относится к `BATTLE-01/02`.

### Проверка результата

Проверять неизменность X/Y и общей статистики при смене страницы/фильтров, гостевое чтение, независимость реакций от библиотеки и отсутствие запрета прямого чтения после скрытия.

### Вопросы интерфейса

Остаётся определить представление пустых состояний и переход в настройку Баттла.

### Чтение состава

Поиск, диапазон общей оценки, сортировка и режимы grouped/flat доступны в [QUERY /collections/:id/items](../../api/contracts/collectionsSpec.md#выдача-item). Личная фильтрация включается явно для главной. Прогресс по подборке читается отдельным GET.
