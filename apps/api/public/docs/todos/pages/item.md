## Произведение

- [ITEM-01 — публичная карточка Item](../catalog/itemDetails.md)
- [x] `ITEM-02`: сверить показатели страницы с ItemStats. Средняя оценка, числа оценок и добавлений в избранное и счётчики пяти статусов уже хранятся в ItemStats.
- [x] Вернуть согласованную статистику страницы в [GET /items/:id](../../api/requestFlows/catalog.md#item).
- [ ] `ITEM-03`: уточнить дополнительный состав статистики для кратких карточек.
- [ ] `ITEM-04`: согласовать достаточность карточки для страницы. Поиск по названию остаётся отдельной задачей `SEARCH-03`.

### Вопросы API

Определить источник внешних ссылок. [Личная запись](../../api/requestFlows/catalog.md#item-user) и [поиск коллекций по ID Item](../../api/requestFlows/catalog.md#search) доступны через API. Плеер и публичное чтение чужих подробных попыток в состав страницы не входят.

### Вопросы интерфейса

При подготовке спецификации определяются точные поля и догрузка блоков, представление неполных переводов и отсутствующего изображения, правила расчёта статистики, отображение удалённого произведения и параметры перехода к коллекциям. Наличие этих блоков в описании страницы не означает, что необходимые операции чтения и пересчёта уже реализованы.
