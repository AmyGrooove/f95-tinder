[Задачи по страницам](readme.md)

## Произведение

- [ITEM-01 — публичная карточка Item](../catalog/itemDetails.md)
- [ ] `ITEM-02`: определить формулы и реализовать расчёт/обновление общей оценки, числа оценок и избранного, распределения библиотеки по статусам; учесть создание, изменение и удаление UserItem. Подготовить общий источник статистики для карточек и страницы.
- [ ] `ITEM-03`: вернуть статистику страницы и нужные показатели кратких карточек; неизвестная оценка не равна нулю. Зависит от `ITEM-02`.
- [ ] `ITEM-04`: согласовать достаточность карточки для страницы. Поиск по названию остаётся отдельной задачей `SEARCH-03`.

### Вопросы API

Статистические формулы, отдельное чтение личной записи по Item и переход к полному списку коллекций. Плеер и публичное чтение чужих подробных попыток в состав страницы не входят.

### Вопросы интерфейса

При подготовке спецификации определяются точные поля и догрузка блоков, представление неполных переводов и отсутствующего изображения, правила расчёта статистики, отображение удалённого произведения и параметры перехода к коллекциям. Наличие этих блоков в описании страницы не означает, что необходимые операции чтения и пересчёта уже реализованы.
