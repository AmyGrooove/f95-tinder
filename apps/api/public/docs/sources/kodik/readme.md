# Kodik: справочные материалы

> Статус на 7 ноября 2026 года: материал описывает проектирование интеграции и сохранённые примеры источника. Source, SourceItem и прежние сервисы импорта отсутствуют в текущем коде. Упоминания этих объектов ниже не означают готовую реализацию. Контракт провайдера и примеры ответов заново по официальной документации не подтверждались; перед подключением их необходимо проверить.

Точки входа и границы реализации — в [обзоре API](../../api/readme.md). Требования к наполнению — в [основах](../../product/foundations/catalogWorkflow.md).
