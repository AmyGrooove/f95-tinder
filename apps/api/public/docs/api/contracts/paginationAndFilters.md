# Пагинация и фильтры

## Пагинация

[Общие типы входа](../../../../src/infrastructure/database/types/IPaginationInput.ts) используют `limit` со значениями `10`, `20` или `50`. `IPagePagination` добавляет `page`, `ICursorPagination` — `cursor`.

| Вариант    | Правила                                                                                                                                                                                                                                                                                                                                                          |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Страничный | [Нормализация](../../../../src/infrastructure/database/functions/normalizePagination/index.ts) подставляет `page=1` и `limit=50`. [Результат](../../../../src/infrastructure/database/types/IPaginationResult.ts) содержит `items`, `page`, `total`, `pages`, `isNextPage` и `isPreviousPage`. Лимит передаётся на вход и используется при расчёте числа страниц |
| Курсорный  | Каждый маршрут определяет состав ответа, привязку курсора и размер порции по умолчанию. [Поиск](searchSpec.md#search) использует `20`, [теги](searchSpec.md#tags) и [состав подборки](collectionsSpec.md#выдача-item) — `50`                                                                                                                                     |

Чтобы продолжить выдачу, передайте полученный `nextCursor` с параметрами, предусмотренными контрактом маршрута. `nextCursor: null` обозначает конец выдачи.

## Общие условия фильтрации

[`IValueFilter<TValue>`](../../../../src/infrastructure/database/types/IValueFilter.ts) определяет необязательные массивы `allOf`, `anyOf` и `noneOf`. Допустимые значения, валидацию и способ применения определяет потребитель. Примеры есть в [контракте поиска и тегов](searchSpec.md).
