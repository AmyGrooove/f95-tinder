## Текущее покрытие

| Сценарий                                       | Состояние          | Основание                                                                                                |
| ---------------------------------------------- | ------------------ | -------------------------------------------------------------------------------------------------------- |
| Каталог произведений, поиск и фильтры          | Частично           | QUERY /search ищет Item; QUERY /tags выдаёт справочник тегов для фильтра поиска                          |
| Каталог и поиск коллекций                      | Частично           | QUERY /search ищет по названиям и описаниям; отдельной выдачи списка подборок по itemIds/type нет        |
| Поиск пользователей                            | Реализован         | QUERY /search ищет по username/displayName и возвращает только публичную карточку                        |
| Карточки с общими оценками и личным состоянием | Частично           | Поиск и состав подборки возвращают краткие карточки Item. [Личные операции](shared.md) работают отдельно |
| Личные действия                                | Реализована запись | Переиспользовать [общие операции](shared.md), не создавать их повторно для каталога                      |

## Правила каталога и рекомендаций

Анонсы по умолчанию участвуют в обычном каталоге. Личные статусы и «Не рекомендовать» не исключают произведения без явно выбранного условия. Скрытые коллекции также доступны по умолчанию, пользовательские коллекции участвуют в прямом поиске без условия допуска на главную. Рекомендательный режим описан в [требованиях страницы](../../product/pages/search.md) и [плане рекомендаций](../../todos/recommendations/implementationPlan.md).
