## Реализованный общий поиск

Параметры групп, фильтры и формат выдачи описаны в [контракте QUERY /search](../contracts/searchSpec.md#search).

Для новинок и популярного главная опускает `search`, выбирает `entities.anyOf: ["items"]` и задаёт `items.sort`. Личные исключения включаются через `isPersonalFilteringEnabled: true`.

## Дальнейшая работа

Клиент может перелистывать каталог по `nextCursor` и хранить полученные курсоры для возврата на посещённые страницы. Для прямого перехода можно использовать смещение в индексной выдаче без личных условий. Для произвольных страниц с личными фильтрами потребуется снимок уже отфильтрованных ID с лимитом глубины и сроком жизни. Смещение по необработанным совпадениям даёт другую нумерацию.

«Популярное» продолжает использовать существующую рейтинговую сортировку Item. Для самостоятельных критериев можно согласовать отдельную сортировку по среднему баллу и метрику популярности с указанными сигналами и периодом. Для сортировки смешанной выдачи по статусу выпуска нужно определить порядок четырёх статусов, позицию неизвестного статуса и разрешение равенств.

## Правила каталога и рекомендаций

Анонсы по умолчанию участвуют в обычном каталоге. Личные статусы и «Не рекомендовать» не исключают произведения без явно выбранного условия. Скрытые коллекции также доступны по умолчанию, пользовательские коллекции участвуют в прямом поиске без условия допуска на главную. Для «Все рекомендации» используется авторизованный [QUERY /recommendations](../requestFlows/catalog.md#recommendations).
