## Текущее покрытие

| Сценарий                    | Состояние              | Что есть / чего не хватает                                                                                                                                                                                                          |
| --------------------------- | ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Дневная лента и догрузка    | API подключён          | [GET /home/feed](../requestFlows/catalog.md#home-feed) возвращает сохранённый порядок. [GET /facts/:id](../requestFlows/catalog.md#fact) читает факт. Остаётся подключить веб-главную                                               |
| Личный блок                 | API подключён          | [`QUERY /account/library/continue`](../requestFlows/account.md#library-continue) выбирает раздел. [`QUERY /users/:id/library`](../requestFlows/userItems.md#user-library) выдаёт карточки с оценками и кратким прогрессом владельца |
| Рекомендации                | Есть                   | [`QUERY /recommendations`](../requestFlows/catalog.md#recommendations) возвращает карточки с общей и личной оценками и статусом зрителя. Для главной переключатель задаётся через `filter.statuses`, блок показывается после входа  |
| Новинки, популярное, анонсы | Частично               | [QUERY /search](../contracts/searchSpec.md#новинки-и-популярное-на-главной) выдаёт новинки и популярное без текста, когда запрос явно выбирает Item, сортировку и личную фильтрацию. Отдельная выдача анонсов пока отсутствует      |
| Официальные коллекции       | Есть                   | Дневная лента выбирает непустые коллекции сайта. [Запрос состава](../contracts/collectionsSpec.md#выдача-item) загружает состав с метаданными, оценками, статусом и личными скрытиями                                               |
| Сохранение переключателей   | Нет готового контракта | Нет операций для настроек главной; место хранения между посещениями ещё не выбрано                                                                                                                                                  |
| Личные действия карточки    | Частично               | Запись покрыта [общими операциями](shared.md). Карточки поиска, рекомендаций и состава коллекций содержат личную оценку и статус                                                                                                    |

## Дальнейшая работа

При подключении главной первый запрос карточек передаёт статус из `QUERY /account/library/continue` в `statuses.anyOf` и тот же массив `types`, который использовался в JSON-теле запроса раздела. Обе операции учитывают только существующие неудалённые Item. Карточка библиотеки содержит `movieDuration` в минутах, когда длительность известна. Её можно использовать вместе с прогрессом в `minute`. Главная пропускает блок при `status: null` или если первая порция опустела между запросами.
