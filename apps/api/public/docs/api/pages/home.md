## Текущее покрытие

| Сценарий                    | Состояние              | Что есть / чего не хватает                                                                                         |
| --------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Дневная лента и догрузка    | Нет                    | Нет пользовательской выдачи ленты, сохранённого дневного порядка и связанного сценария его формирования            |
| Личный блок                 | Частично               | Статусы записываются через UserItem; чтения первой непустой категории inProgress → onHold → planned нет (`LIB-02`) |
| Рекомендации                | Нет                    | Нужны `REC-01/02`; гостю — стартовые рекомендации без личных данных                                                |
| Новинки, популярное, анонсы | Нет                    | Нет соответствующих публичных выдач; модели Item и метрик не равны готовым блокам                                  |
| Официальные коллекции       | Частично               | Можно читать известную коллекцию и её состав; нет выбора коллекций для ленты и выдачи их карточек со всеми данными |
| Сохранение переключателей   | Нет готового контракта | Нет операций для настроек главной; место хранения между посещениями ещё не выбрано                                 |
| Личные действия карточки    | Частично               | Запись покрыта [общими операциями](shared.md); получение личного состояния в ленте ещё нужно                       |
