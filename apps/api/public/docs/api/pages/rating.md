## Текущее покрытие

| Сценарий                            | Состояние         | Контракт                                                                                                                                                                                                                       |
| ----------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Очередь completed без личной оценки | Реализовано в API | [QUERY /users/:id/library](../contracts/librarySpec.md#публичный-список-библиотеки) с `isUnrated: true` и `statuses.anyOf: ["completed"]` выдаёт владельцу карточки с `userItemId` и продолжается по дате создания и ID записи |
| Поставить оценку                    | Реализовано в API | [PATCH /userItems/:id](../contracts/librarySpec.md#изменение-личных-полей) с `rating` от 1 до 10 и `isCompletedAndUnratedRequired: true` сохраняет оценку только для всё ещё подходящего кандидата                             |
| Карточка и краткий просмотр         | Общий контракт    | [GET /items/:id](../requestFlows/catalog.md#item) для публичных данных произведения по `id` карточки                                                                                                                           |
| Пропустить кандидата                | На клиенте        | Клиент переходит к следующему кандидату. Пропущенный может снова появиться при новом проходе с первой страницы                                                                                                                 |

У пропуска нет HTTP-запроса. `POST /userItems/skip` создаёт временное исключение из рекомендаций. Сервер хранит только обычные данные библиотеки.
