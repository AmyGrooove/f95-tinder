## Текущее покрытие

| Сценарий                  | Состояние | Что есть / чего не хватает                                                                                                                                                                    |
| ------------------------- | --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Публичные данные фильма   | Нет       | Поиск и коллекции возвращают краткие карточки                                                                                                                                                 |
| Личная запись и попытки   | Частично  | Изменения реализованы; есть краткое QUERY-чтение по ID UserItem; загрузки по Item и подробных попыток при открытии страницы нет (`LIB-01`)                                                    |
| «Не рекомендовать»        | Частично  | Создание blocked, смена статуса и удаление через UserItem есть; чтения по Item нет; QUERY /userItems требует известный ID UserItem (`LIB-01`), применение в рекомендациях остаётся в `REC-02` |
| Общая статистика          | Нет       | В текущих ответах нет оценки, числа оценок/избранного и распределения по пяти статусам; UserItemService не пересчитывает эти метрики                                                          |
| Связи и кадры             | Нет       | Для страницы требуется чтение прямых связей и медиа                                                                                                                                           |
| Внешние ссылки            | Нет       | Данные об источниках недоступны через API страницы                                                                                                                                            |
| Коллекции с произведением | Частично  | QUERY /collections с itemIds и type возвращает страницы кратких карточек; type=franchise выбирает франшизы сайта; размер и общая оценка коллекции не возвращаются                             |

## Дальнейшая работа

[Задачи и вопросы](../../todos/pages.md#произведение)

Заметка, личный прогресс и подробные попытки доступны только владельцу. Плеер и публичное чтение чужих подробных попыток в состав страницы не входят.
