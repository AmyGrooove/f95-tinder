## Текущее покрытие

| Сценарий                      | Состояние   | Что есть / чего не хватает                                                                                                                                                            |
| ----------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Публичные данные произведения | Реализовано | [GET /items/:id](../requestFlows/catalog.md#item) возвращает подробную карточку гостю                                                                                                 |
| Личная запись и попытки       | Реализовано | [GET /items/:id/user](../requestFlows/catalog.md#item-user) загружает свою запись, заметку и попытки. Изменения выполняются через [маршруты библиотеки](../requestFlows/userItems.md) |
| «Не рекомендовать»            | Реализовано | Личный маршрут возвращает `blocked`. [Маршруты библиотеки](../contracts/librarySpec.md#реализованные-операции-библиотеки) позволяют установить и снять статус                         |
| Общая статистика              | Реализовано | [Публичная карточка](../../todos/catalog/itemDetails.md) содержит среднюю оценку, числа оценок и добавлений в избранное и счётчики пяти библиотечных статусов                         |
| Связи и кадры                 | Реализовано | Публичная карточка включает медиа и прямые связи в обоих направлениях                                                                                                                 |
| Внешние ссылки                | Нет         | Источник внешних ссылок предстоит выбрать                                                                                                                                             |
| Подборки с произведением      | Реализовано | [QUERY /search](../requestFlows/catalog.md#search) с `collections.itemId` возвращает первые карточки и последующие страницы по курсору                                                |

## Дальнейшая работа

[Задачи и вопросы](../../todos/pages/item.md#item)

Заметка, личный прогресс и подробные попытки доступны только владельцу. Плеер и публичное чтение чужих подробных попыток в состав страницы не входят.
