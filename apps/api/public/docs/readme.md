Для работы с исходниками используйте карты [API](../../agents/index.md) и [веб-приложения](../../../web/agents/index.md).

При расхождении описания с кодом сверяйте фактическое поведение с исходниками. Требования и объём этапа сверяйте с продуктовой спецификацией и планом соответствующей задачи. Исследовательские предложения и материалы Bisky v3 относятся к указанным в них версиям.

## Стадия разработки и миграции

Проект находится на стадии разработки. При изменении схем и контрактов миграции, backfill и поддержка старых форматов нужны только при явном запросе сохранить или перенести конкретные данные. Упоминания миграций в отдельных документах описывают последствия для старых данных. Удаление и сброс БД требуют отдельного решения.

## Соглашения об именовании

Составные имена сегментов API и файлов документации пишем в camelCase, например `/userItems`, `/account/displayName` и `accountAndAuthSpec.md`.

## Как читать статусы

- **API** описывает подключённые контроллеры, DTO и фактические ограничения исходников. Наличие метода не подтверждает успешный запуск приложения.
- **Продукт** описывает целевое поведение. Отсутствующие возможности отмечаются в покрытии страниц и задачах.
- **Задачи** отделяют согласованный объём от открытых решений и завершённых частей.
- **Исследования и Bisky v3** сохраняют исторические результаты; старые команды, модели и замеры нельзя считать характеристиками текущей версии.

Сверка 7 ноября 2026 года выполнялась по текущим исходникам. Работающая БД, внешние сервисы и тесты не запускались. Production-проверка TypeScript выявила незавершённую интеграцию курсорных рекомендаций; подробности — в [статусе рекомендаций](api/readme.md#recommendations).

Документация открывается через `/knowledge/`. Ссылки на исходники и импортные данные вне этой базы предназначены для локального checkout: оболочка не публикует их как HTTP-файлы.

Практические точки входа: [различия Item ID и UserItem ID](api/pages/shared.md#какие-id-хранит-клиент), [сохранение коллекции и конфликт версии](api/pages/collectionEditor.md#версия-и-сохранение-формы), [пагинация](api/contracts/paginationAndFilters.md).
