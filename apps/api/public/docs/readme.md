При расхождении описания с кодом сверяйте фактическое поведение с исходниками. Требования и объём этапа сверяйте с продуктовой спецификацией и планом соответствующей задачи. Исследовательские предложения и материалы Bisky v3 относятся к указанным в них версиям.

## Стадия разработки и миграции

Проект находится на стадии разработки. При изменении схем и контрактов миграции, backfill и поддержка старых форматов нужны только при явном запросе сохранить или перенести конкретные данные. Упоминания миграций в отдельных документах описывают последствия для старых данных. Удаление и сброс БД требуют отдельного решения.

## Соглашения об именовании

Составные имена сегментов API и файлов документации пишем в camelCase, например `/userItems`, `/account/displayName` и `accountAndAuthSpec.md`.
