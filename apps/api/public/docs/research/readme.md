## Границы воспроизводимости

Исследовательские отчёты описывают состояние кода и наборы данных на дату эксперимента. При сверке документации 7 ноября 2026 года эксперименты не повторялись. Удалённые сервисы, локальные временные пути и прежние формулы в отчётах сохраняются как исторический контекст. Текущую реализацию проверяйте по [обзору API](../api/readme.md#recommendations), принятые решения — по [плану](../todos/recommendations/implementationPlan.md).

При сравнении результатов важны источник и дата данных, разделение обучения и проверки, набор кандидатов, обработка неизвестных Items и пользователей, а также одинаковые фильтры. Улучшение offline-метрики не доказывает полезность интерфейса или производительность MongoDB. Синтетический эксперимент проверяет заданный сценарий, но не распределение интересов реальных пользователей.
