# Архив предыдущего Bisky: Swagger и Bisky_v3

Старые макеты и Swagger — **референсы для исследования возможных страниц, данных и сценариев нового приложения**. Они не являются обязательным дизайном, архитектурой, контрактом API или согласованным объёмом нового Bisky. Приоритет имеют [основы](../product/foundations.md), [MVP](../product/mvpScope.md) и [контракт аккаунта](../api/accountAndAuthSpec.md); архив их не изменяет.

Обновлено 21 октября 2026 года по 58 desktop-экспортам пользователя. Прежние сведения о странице Pages файла [Bisky_v3](https://www.figma.com/design/2wTWhzXTr81bOYt5Zio7Ez/Bisky_v3?node-id=1-355) сохранены. Повторного обращения к Figma не было.

## Источники и реестры

- [swaggerOriginal.txt](swaggerOriginal.txt) — дословный прежний текстовый список. OpenAPI и изображений Swagger нет.
- [swaggerEndpoints.json](swaggerEndpoints.json) — все 100 исходных записей без изменения методов, путей, описаний и порядка.
- [screenApiMap.json](screenApiMap.json) — те же 100 записей со связями, оговорками и новыми путями PNG; это не новый API.
- [screensManifest.json](screensManifest.json) — все 187 прежних фреймов: 58 Desktop, 60 Mobile, 55 Modals, 14 MiniMenu. Для desktop — исходное имя файла, новое имя, размеры PNG, SHA-256, наблюдения, отличия, кандидаты старого API и полный просмотр. Для остальных — screenshot: null и отсутствие новой визуальной проверки. Поле file у них — историческое обозначение, не существующий локальный файл; наличие PNG определяется только screenshot.
- [figmaTexts.json](figmaTexts.json) — прежнее извлечение текстов 187 фреймов, без нового распознавания PNG. Оно не заменяет визуальные наблюдения: при расхождении desktop описывается по изображению, старый текст остаётся источником сравнения.
- Папка screenshots/desktop содержит 58 пользовательских PNG, только переименованных; байты и варианты сохранены. Имена — латиница, camelCase, отдельные суффиксы вкладок и состояний.

## Полнота и границы проверки

1. Изучены архивные описания и актуальная документация, включая пять вложенных разделов основ и спецификацию аккаунта.
2. Обнаружены 58 изображений, все desktop; каждое просмотрено полностью, включая низ длинных страниц. Области карточки, плеера, коллекции и достижений дополнительно увеличены.
3. Каждое изображение сопоставлено с одним прежним desktop-фреймом по уникальному исходному имени, точным размерам и содержимому. Figma ID взяты из старого реестра, не извлечены из PNG. Все варианты учтены отдельно, перезаписей нет.
4. Mobile, модальные окна и меню — сведения прежнего исследования, **не проверенные новыми экспортами**. Закрытое меню или кнопка открытия окна не подтверждают его содержимое.
5. Старые приложение и сервер не запускались; переходы, HTTP-запросы, доступность кнопок и серверные правила не проверялись. Сетевая доступность Figma и старых внешних ссылок не проверялась.

**Наблюдение** — видимый блок, подпись или состояние. **Сопоставление** — кандидат связи со старым маршрутом. **Предложение** — вариант для нового продукта, требующий отдельного решения. Неподписанные иконки, числа и даты не получают выдуманного значения; повторённые карточки не задают лимиты и формулы.

24 октября 2026 года добавлена [статическая сверка с исходниками](implementation.md). Она уточняет часть API и серверных правил, но не является сетевой трассировкой или новым просмотром Figma. Для кода фиксируются коммиты: локальный `main`, `origin/main` и `dev` могут содержать разные реализации. Архивные 100 записей Swagger и реестры изображений сохранены как исходные свидетельства, включая расхождения с кодом.
