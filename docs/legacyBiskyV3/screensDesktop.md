# Bisky_v3 — проверенные desktop-экспорты

[Навигатор](readme.md) · [Галерея](screenshots.md) · [Исходные и новые имена](screenshotRenames.md) · [Сценарии](pagesAndFlows.md)

Все 58 PNG полностью просмотрены 21 октября 2026 года, включая низ длинных страниц. Детали карточки, плеера, коллекции и достижений дополнительно увеличены. Это статические изображения предыдущего проекта, не требования к новому Bisky и не проверка работающего интерфейса.

Figma ID сопоставлены по уникальному исходному имени, точным размерам и содержимому архивного фрейма; это сопоставление с прежним реестром, без нового чтения Figma. Исходные названия и тексты сохранены в [figmaTexts.json](figmaTexts.json), соответствие имён и SHA-256 — в [реестре](screensManifest.json).

**Как читать:** «Наблюдение» описывает пиксели и подписи; «Действия» — видимые возможности интерфейса без подтверждения выполнения; «Старый API» — кандидаты по Swagger, а не трассировка запросов. DTO, права, формулы и смысл неподписанных иконок не восстанавливаются. Числа, даты и повторённые карточки — примеры. Общая шапка (коллекции, инструменты, AnimePass, поиск Ctrl + K, колокольчик, аватар) и подвал с документами повторяются; их наличие не означает загрузку отдельного API на каждом экране.
