[Навигатор архива](readme.md) · [Сценарии](pagesAndFlows.md) · [Связь с API](screenApiMap.md)

Это реестр фреймов, а не утверждённые URL сайта. Тексты извлечены из видимых узлов, в том числе внутри экземпляров компонентов; видимость проверена по цепочке родителей. Повторы одинакового текста внутри одного фрейма удалены. Общая навигация опущена из перечней ниже; полный набор сохранён в figmaTexts.json. Геометрия, порядок чтения текстов и подписи сами по себе не доказывают работоспособность или переходы прототипа.

**Статус обновления:** новых изображений этой группы не предоставлено. Ни один фрейм этой группы не отмечен проверенным по новым desktop-экспортам. Подписи, размеры и ссылки ниже сохранены из прежнего исследования; это не новая визуальная проверка.
