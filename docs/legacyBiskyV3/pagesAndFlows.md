## Общие элементы интерфейса

Desktop-шапка содержит логотип, коллекции, инструменты, AnimePass, поиск с подсказкой `Ctrl + K`, уведомления и аватар. Подвал содержит ссылки «О сайте», «Поддержка», «API», документы, соцсети и копирайт.

На mobile есть компактная шапка и нижняя панель навигации. Содержимое некоторых крупных блоков вынесено в вкладки или дополнительные окна. В частности, для клубов и персон явно есть мобильные вкладки «Инфо», а компактный АниПик не выводит рядом весь текст desktop-карточки.

Прежнее описание меню аккаунта `4181:35046` сохраняет имя пользователя, профиль, настройки и поддержку; меню `4181:35039` — главную и коллекции. Эти сведения не перепроверены новыми экспортами; извлечённые тексты в реестре меню не отражают все перечисленные переходы. Мобильный «Быстрый доступ» `4201:16912` содержит настройки и три инструмента по прежним материалам.

## Как читать реестры

В [desktop](screensDesktop.md), [mobile](screensMobile.md), [модальных окнах](screensModals.md) и [меню](screensMenus.md) есть запись на каждый фрейм. ID определяет конкретный вариант даже при совпадении названия. В desktop каждой записи соответствует новый локальный PNG; для остальных групп локальных изображений нет. Например, `Авторизация` обозначает несколько разных шагов, а один мобильный фрейм `Список аниме` фактически содержит комментарии.

Связи между страницами в тематических описаниях восстановлены по кнопкам и текстам; кликабельный прототип не проходился. Поведение иконки без явной подписи не считается установленным только по её внешнему виду.
