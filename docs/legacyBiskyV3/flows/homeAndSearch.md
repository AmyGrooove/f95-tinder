# Главная, поиск и навигация

[Карта страниц](../pagesAndFlows.md) · [Старый Swagger](../swagger.md)

**Источники:** desktop-сведения сверены с новыми экспортами; [описание каждого из 58 состояний](../screensDesktop.md) содержит наблюдения и ограничения. Mobile, модальные окна и меню ниже — сведения прежнего исследования, не проверенные новыми изображениями. Связи со Swagger являются сопоставлениями, а не трассировкой запросов.

## Главная

Опорные фреймы: desktop `3970:7991`, mobile `4163:14714`. [Локальный снимок desktop](../screenshots/desktop/home.png).

Наблюдаемый состав:

1. Большая карусель произведений с фоновым изображением, постером, названием, рейтингом и дополнительной строкой названий.
2. «Продолжить просмотр»: горизонтальные карточки с названием, эпизодом или временем и полосой прогресса.
3. «Новые серии»: ряд карточек, количество вышедших/всех эпизодов либо отметка «Релиз», переход «Онгоинги» на desktop.
4. Информационный факт с текстом, источником, автором и значком жалобы.
5. «Топ-100» и переход к полному списку.
6. Баннер АниПик с описанием инструмента и кнопкой «Попробовать».

Мобильный вариант сохраняет эти семейства блоков, горизонтальные ряды и нижнюю навигацию. Карусель и ряды показывают неполные соседние карточки; данные макетов не задают размер API-пакета или способ догрузки.

Связанные старые маршруты:

- `GET /home` — получение главной по описанию пользователя.
- `GET /home/row` — получение элемента главной; его идентификация и query неизвестны.
- `GET /home/collections` — маршрут есть, но точный состав данных не указан.
- `GET /home/user/watch` — по имени сопоставляется с «Продолжить просмотр»; тело ответа неизвестно.
- `POST /mainFeed` — генерация ежедневной главной ленты. Это серверная операция, не доказанный запрос при каждом открытии главной.

Границы между `/home`, `/home/row`, `/home/collections` из макета не следуют. Статическая [сверка legacy-кода](../implementation.md) уточняет: `/home` возвращает `seasonalAnimes`, `newEpisodeAnimes`, `bestAnimes`, а `/home/row` принимает `elementIndex` 1–100 и возвращает элемент подготовленной ленты с `isEnd`. Клиент `MainPage` использует эти данные и догружает ряды через `useInfiniteGetHomeRow`. `/home/collections`, `/home/user/watch` и блок «Продолжить просмотр» в проверенных HomeController/MainPage не подтверждены. Это расхождение источников, не доказательство удаления функции из production.

Для дальнейшей адаптации: фильмы вместо эпизодного каталога, смысл «продолжения» без встроенного плеера и источник рейтинга требуют отдельного решения. Макет не задаёт персональные рекомендации на главной автоматически.

## Поиск

Фреймы: desktop `4011:8158` и `4011:8499`; mobile `4182:15519` и `4182:15712`. [Снимок результатов](../screenshots/desktop/searchResults.png).

Начальное состояние содержит поисковую строку, фильтр, сортировку, переключатели типов результатов и предложение воспользоваться поиском либо АниПик/АниБаттл/АниСудьёй.

В desktop-результатах одновременно показаны пользователи, сетка аниме, коллекции, клубы озвучки и персоны. В mobile-фрейме результатов видны карточки аниме, их названия и рейтинг. Отсутствие других блоков в одном мобильном фрейме не доказывает отсутствие поиска этих типов в приложении.

Старый маршрут: `GET /search`. В [проверенном коде](../implementation.md) query содержит `search` и необязательный `searchType` (`Anime`, `Collection`, `DubClub`, `User`); Meilisearch определяет ID и порядок, MongoDB возвращает данные. Без типа возвращаются четыре группы, отсутствие результатов во всех группах даёт 404. Поиск персон, фильтры макета, сортировка и пагинация этим DTO не подтверждены; debounce из серверного контракта не следует.

Окно `FilterModal` (`4181:34883`) показывает типы «Сериал», «Фильм», «OVA», «ONA», «Спешл»; статусы «Релиз», «Онгоинг», «Анонс»; сезоны; возрастные отметки; период выхода; кнопки сброса и применения. Это старый аниме-фильтр, а не готовый контракт фильтрации фильмов Bisky.

В `MiniMenu` сохранены шесть вариантов сортировки (`4181:34977`…`4181:35018`): популярность, новизна, количество, порядок по умолчанию и случайный порядок в разных сочетаниях. По одним названиям `SortMenu` нельзя однозначно назначить каждый вариант конкретной странице.
