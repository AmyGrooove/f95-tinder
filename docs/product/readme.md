# Продукт и требования

Эти документы описывают согласованные принципы и планируемый объём. Реализованные сценарии и ограничения кода находятся в [разделе API](../api/readme.md).

| Когда читать                                       | Документ                           |
| -------------------------------------------------- | ---------------------------------- |
| Цели системы, модель произведения и общие принципы | [Основы проекта](foundations.md)   |
| Объём первой версии и порядок дальнейших этапов    | [Границы MVP](mvpScope.md)         |
| Страницы, их назначение и вопросы для спецификаций | [Карта страниц](pages/readme.md)         |
| Идеи продукта за пределами текущего этапа          | [Полный замысел](productVision.md) |

Основы разделены по темам: [данные](foundations/dataStructure.md), [наполнение каталога](foundations/catalogWorkflow.md), [рекомендации](foundations/recommendations.md), [библиотека](foundations/library.md), [расширяемость](foundations/extensibility.md).

Отложенный пункт первоначального MVP может получить отдельно согласованную реализацию: например, публичные подборки уже имеют [собственный контракт](../api/collectionsSpec.md). Это не означает автоматического включения остальных идей в ближайший этап.
