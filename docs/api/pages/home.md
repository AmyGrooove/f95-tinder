# Главная: покрытие API

[Индекс покрытия](readme.md) · [Требования страницы](../../product/pages/home.md) · [Общие операции](shared.md)

## Текущее покрытие

| Сценарий | Состояние | Что есть / чего не хватает |
| --- | --- | --- |
| Дневная лента и догрузка | Нет | Нет пользовательской выдачи ленты, сохранённого дневного порядка и связанного сценария его формирования |
| Личный блок | Частично | Статусы записываются через UserItem; чтения первой непустой категории inProgress → onHold → planned нет (`LIB-02`) |
| Рекомендации | Нет | Нужны `REC-01/02`; гостю — стартовые рекомендации без личных данных |
| Новинки, популярное, анонсы | Нет | Нет соответствующих публичных выдач; модели Item и метрик не равны готовым блокам |
| Официальные коллекции | Частично | Можно читать известную коллекцию и её состав; нет выбора коллекций для ленты и выдачи их карточек со всеми данными |
| Сохранение переключателей | Нет готового контракта | Нет операций для настроек главной; место хранения между посещениями ещё не выбрано |
| Личные действия карточки | Частично | Запись покрыта [общими операциями](shared.md); получение личного состояния в ленте ещё нужно |

## Осталось

- [ ] `HOME-01`: определить и реализовать выдачу фиксированного начала и дополнительной части, догрузку с сохранением дневного порядка и явное окончание ленты. Фиксированное начало не входит в лимит; дополнительных блоков не более 20. Пустые блоки пропускаются, повторами лента не заполняется.
- [ ] `HOME-02`: реализовать ежедневное формирование и сохранение общего порядка дополнительных блоков; четыре коллекции → факт → однократные анонсы, далее четвёрки коллекций со вставкой факта или инструмента. Открытая лента сохраняет порядок при смене дня до обновления страницы.
- [ ] `HOME-03`: сформировать данные блоков: новинки по выходу, популярное по собственной активности сайта, анонсы, факты и только официальные коллекции. Подключить `LIB-02`, `REC-01/02`, публичные карточки и статистику из [каталога](search.md) и [произведения](item.md).
- [ ] `HOME-04`: определить хранение выбранных типов и переключателей между посещениями; реализовать backend-часть, если она нужна. По умолчанию скрывать completed/dropped, скрытые коллекции и «Не рекомендовать»; условия распространяются и на произведения внутри блоков коллекций.

## Уточнить

Размеры рядов, периоды новизны и популярности, сигналы активности, подбор официальных коллекций, источники фактов, чередование вставок и повторы Item между блоками. Выбор одного/нескольких типов, недостаток анонсов и формат продолжения ленты требуют контракта. Для MVP допускается только movie.

Переходы «Посмотреть все» требуют соответствующих режимов [каталога](search.md), библиотеки или коллекции и передачи применимых условий. Выключение скрытия не отменяет обязательный запрет «Не рекомендовать» внутри рекомендаций. Эти переходы не означают отдельный endpoint для каждой кнопки.

## Проверка результата

Проверять порядок и общий лимит блоков, единственность анонсов, окончание без повторов, продолжение через смену дня, пропуск пустых блоков, гостевую выдачу и личные исключения. Runtime-проверки не выполнялись.
