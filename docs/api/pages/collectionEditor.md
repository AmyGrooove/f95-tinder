# Редактор коллекции: покрытие API

[Индекс покрытия](readme.md) · [Требования страницы](../../product/pages/collectionEditor.md) · [Контракт коллекций](../collectionsSpec.md)

## Реализовано

| Маршрут | Покрытие |
| --- | --- |
| `POST /collections` | Создание своей публичной коллекции с названием, описанием, типом, media, блоками и включениями Item |
| `PATCH /collections/:id` | Атомарные изменения метаданных, блоков, включений, заметок, групп и порядка; обязательная version |
| `GET /collections/:id` | Загрузка метаданных, version и полной структуры блоков |
| `QUERY /collections/:id/items` | Постраничная загрузка состава с groupId, position и note включений |
| `DELETE /collections/:id` | Мягкое удаление своей коллекции |

Код: [CollectionController](../../../apps/api/src/endpoints/collection/controllers/collection.controller.ts), [CollectionService](../../../apps/api/src/endpoints/collection/services/collection.service.ts) и [CollectionContentService](../../../apps/api/src/endpoints/collection/services/collectionContent.service.ts).

PATCH принимает изменения (`upsertBlocks`, `removeBlockIds`, `blockOrder`, `upsertItems`, `removeItemIds`), поэтому не требует отправлять весь постранично загруженный состав. Проверяются автор, ссылки на группы и дубли; устаревшая version даёт 409. При удалении группы удаляются её включения, без автоматического переноса. Состав и UserItem независимы. Чтение метаданных после записи не заменяет перечитывание изменённого состава.

## Осталось

- [ ] `EDITOR-01`: определить и реализовать загрузку обложки с использованием существующего транспорта media или согласованного нового контракта. Сейчас создание/изменение принимает ссылки и метаданные media, но само не загружает файл. Проверить инфраструктуру [storage и images](../../../apps/api/docs/agents/storage.md).
- [ ] `EDITOR-02`: согласовать сценарий загрузки/редактирования постраничного состава и обработки 409. Проверить достаточность текущих чтений для выбранной формы; менять backend только при подтверждённом пробеле, не вводить второй CRUD коллекции.

Поиск добавляемых произведений — зависимость `SEARCH-01/02`, а не новый поиск внутри редактора. Превью выбранного произведения использует `ITEM-01` в нужном объёме.

## Уточнить

Выбор типа коллекции, работа с RU/EN, требования к обложке, сохранение формы при конфликте версии и при частично загруженном составе. Очерёдность локальных действий, кнопка сохранения и предупреждение об уходе относятся к клиенту; сервер уже выполняет единый PATCH атомарно. Управление официальными коллекциями обычному автору не предоставляется.

## Проверка результата

Проверять сохранение перестановок и переносов без потери незагруженных включений, конфликты version, уникальность Item, удаление группы и отсутствие изменений библиотеки. Runtime-проверки не выполнялись.
