# Просмотр коллекции: покрытие API

[Индекс покрытия](readme.md) · [Требования страницы](../../product/pages/collection.md) · [Контракт коллекций](../collectionsSpec.md)

## Реализовано

| Маршрут | Покрытие |
| --- | --- |
| `GET /collections/:id` | Метаданные, authorId, version, медиа, полная структура group/text без списков Item, даты |
| `GET /collections/:id/items` | Единая пагинация Item, grouped/flat, авторский порядок или название, поиск, теги/характеристики и личные фильтры; заметки включений |
| `GET /collections/:id/filters` | Доступные теги, числовые/датовые/булевы характеристики и режимы; необязательный groupId |
| `GET /collections/:id/user` | Собственная оценка коллекции, избранное и скрытие |
| `PATCH /collections/:id/rating` | Целая оценка 1–10 или null; автору нельзя поставить оценку своей коллекции |
| `PATCH /collections/:id/favorite` | Избранное коллекции |
| `PATCH /collections/:id/hidden` | Личное скрытие, без запрета прямого чтения |
| `DELETE /collections/:id` | Мягкое удаление автором; операция редактора также доступна отсюда |

Код: [CollectionReadController](../../../apps/api/src/endpoints/collection/controllers/collectionRead.controller.ts), [CollectionContentService](../../../apps/api/src/endpoints/collection/services/collectionContent.service.ts), [CollectionService](../../../apps/api/src/endpoints/collection/services/collection.service.ts), [CollectionUserService](../../../apps/api/src/endpoints/collection/services/collectionUser.service.ts).

При чтении состава авторизованному пользователю возвращаются ID UserItem, статус, личная оценка, избранное и текущая попытка; заметка библиотеки и полная история попыток не выдаются. Гостю доступен состав без личных данных; личные фильтры требуют входа, переданная недействительная cookie даёт 401.

«Скрыть завершённое» пока не покрыто корректным серверным условием: statuses использует включение по `userItem.status` и исключает произведения без UserItem. Выбор остальных четырёх статусов поэтому не заменяет исключение completed. Основание — [createCollectionItemsPipeline](../../../apps/api/src/entities/collectionItem/functions/createCollectionItemsPipeline/core/createCollectionItemsPipeline.ts).

## Чего не хватает

| ID | Состояние | Пробел |
| --- | --- | --- |
| COLLECTION-01 | Частично | Шапка содержит authorId, но не публичное представление автора; нет общей оценки/числа оценок и избранного. total состава — число совпадений с фильтрами, а не гарантированное число всей коллекции |
| COLLECTION-02 | Нет | Нет «Завершено X из Y» по всей коллекции независимо от фильтров и страницы |
| COLLECTION-03 | Частично | Есть личные фильтры включения, но нет исключения completed с сохранением произведений вне библиотеки |
| Карточки произведений | Частично | Ответ `/items` не содержит общей оценки Item; расширение согласовать с `ITEM-03` |
| Запуск Баттла | Частично | Источник состава есть; подготовка набора и остальная ответственность описаны в `BATTLE-01/02` |

- [ ] `COLLECTION-01`: определить расчёт/обновление и чтение общей статистики, полного числа доступных произведений и публичных данных автора/отметки сайта. Использовать `PROFILE-01` или согласованное краткое представление автора; не раскрывать защищённый `/account`.
- [ ] `COLLECTION-02`: определить и реализовать полный личный прогресс X/Y, учитывая удалённые произведения. Не рассчитывать его по одной странице или выдаче с активными фильтрами.
- [ ] `COLLECTION-03`: согласовать и реализовать условие «Скрыть завершённое» до пагинации с сохранением Item вне библиотеки; по умолчанию выключено. Расширить существующее чтение состава, не создавать отдельный маршрут для переключателя.

## Уточнить

Формулы статистики, правила X/Y при удалённых Item, пустые состояния и переход в настройку Баттла. Официальность определяется `authorId=null`; обычные пользовательские маршруты не управляют коллекциями сайта. Административные операции не входят в задачу страницы.

## Проверка результата

Проверять неизменность X/Y и общей статистики при смене страницы/фильтров, гостевое чтение, независимость реакций от библиотеки и отсутствие запрета прямого чтения после скрытия. Runtime-проверки не выполнялись.
