# Произведение: покрытие API

[Индекс покрытия](readme.md) · [Требования страницы](../../product/pages/item.md) · [Общие операции](shared.md)

## Текущее покрытие

| Сценарий | Состояние | Что есть / чего не хватает |
| --- | --- | --- |
| Публичная страница фильма | Нет | Нет самостоятельного чтения Item с описанием, альтернативными названиями, возрастной отметкой, характеристиками, статусом/датой выхода и медиа |
| Личная запись и попытки | Частично | Изменения реализованы; есть краткое QUERY-чтение по ID UserItem; загрузки по Item и подробных попыток при открытии страницы нет (`LIB-01`) |
| «Не рекомендовать» | Частично | Создание blocked, смена статуса и удаление через UserItem есть; чтения по Item нет; QUERY /userItems требует известный ID UserItem (`LIB-01`), применение в рекомендациях остаётся в `REC-02` |
| Общая статистика | Нет | В текущих ответах нет оценки, числа оценок/избранного и распределения по пяти статусам; UserItemService не пересчитывает эти метрики |
| Внешние ссылки, связи, франшиза, кадры | Нет публичного контракта страницы | Нужны данные чтения; наличие связанных сущностей не означает готовый endpoint |
| Коллекции с произведением | Нет | Нет выдачи коллекций по присутствию Item |

## Осталось

- [ ] `ITEM-01`: определить и реализовать публичное чтение фильма со всеми известными данными шапки, описанием, тегами/характеристиками, внешними ссылками, связями/франшизой и кадрами. Выбрать, что входит в основной ответ, а что догружается; данные должны подходить и для краткого просмотра инструментов.
- [ ] `ITEM-02`: определить формулы и реализовать расчёт/обновление общей оценки, числа оценок и избранного, распределения библиотеки по статусам; учесть создание, изменение и удаление UserItem. Подготовить общий источник статистики для карточек и страницы.
- [ ] `ITEM-03`: вернуть статистику страницы и нужные показатели кратких карточек; неизвестная оценка не равна нулю. Зависит от `ITEM-02`.
- [ ] `ITEM-04`: определить и реализовать список публичных коллекций с данным произведением, включая полный список с пагинацией. Согласовать с `SEARCH-03`, не дублировать общий механизм выдачи коллекций.

Личные данные и действия закрываются общими `LIB-01` и `REC-02`; их не нужно повторно реализовывать в публичном ответе Item. Заметка, личный прогресс и подробные попытки доступны только владельцу. Гость читает публичные сведения.

## Уточнить

Поля и догрузку блоков, неполные переводы, отсутствие изображения, удалённый Item, статистические формулы и переход к полному списку коллекций. Плеер и публичное чтение чужих подробных попыток в состав страницы не входят.

## Проверка результата

Проверять полноту известных данных и пустые блоки, переходы skipped/blocked и сохранность личных данных, приватность личных полей и изменение статистики после мутаций. Runtime-проверки не выполнялись.
